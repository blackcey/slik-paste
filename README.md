# SLIK Paste

Chrome / Edge extension. Takes a list on your clipboard (from a spreadsheet column, a row, a 2-D range, a CSV, plain text, etc.) and pastes it into the focused text field as `=v1;=v2;=v3;` — the discrete-value filter syntax IFS search screens accept.

## How it works

1. Copy a list of values to your clipboard. Sources can be:
   - A column, row, or 2-D range from Excel / Google Sheets
   - A semicolon- or comma-separated string
   - A single value
2. Click into a text field on a web page.
3. Right-click → **SLIK Paste: IFS Discrete Values**

The extension auto-detects the delimiter using this priority:

```
tab / newline (spreadsheet) > semicolon > comma > (single value)
```

Spreadsheet content is parsed with a state machine that respects Excel's CSV quoting (cells wrapped in `"..."` may contain tabs, newlines, commas, and `""`-escaped quotes). 2-D ranges are flattened into a single value list. Each value is trimmed, internal line breaks become a single space, empty entries are dropped, and the result is joined with `;` and a trailing `;`. Values containing spaces are preserved intact.

### Example

Clipboard (copied from an Excel column):
```
ACME Corp
"Globex, Inc."
Initech

Umbrella
```

Pasted into the focused field:
```
=ACME Corp;=Globex, Inc.;=Initech;=Umbrella;
```

## Installing (developer mode)

1. Open `chrome://extensions` (Chrome) or `edge://extensions` (Edge).
2. Toggle **Developer mode** on.
3. Click **Load unpacked** and select this folder.

The extension is now active. Right-click in any editable field to see the menu item.

## Files

- `manifest.json` — Manifest V3 declaration
- `background.js` — service worker: registers the context menu and injects the paste logic into the active tab
- `icon{16,32,48,128}.png` — extension icons (generated by `make_icons.py` from the SLIK logo)
- `PRIVACY.md` — privacy policy (no data collected, stored, or transmitted)
